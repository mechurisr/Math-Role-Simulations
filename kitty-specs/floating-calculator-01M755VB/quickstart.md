# Quickstart: 공통 엔진 떠 있는 미니 계산기

## 확인 명령

```bash
pnpm check                                   # 타입 + 의존 규칙 + 단위 테스트 (expression.test.ts 포함)
pnpm exec playwright test e2e/calculator.spec.ts
pnpm test:e2e                                # 전체 (기존 테스트 무수정 통과, NFR-003)
pnpm dev                                     # /episodes/02-race-engineer/
```

## 손으로 확인 (360×640, 개발자 도구 휴대폰 화면)

1. `/episodes/02-race-engineer/?from=M3`로 M3부터 열고 무전 입력 단계까지 넘긴다
2. 카드 위쪽 오른쪽 모서리 바로 위에 원형 버튼이 보이는지 본다 (C1)
3. 버튼 → 계산기가 버튼 왼쪽에 펼쳐지고 카드가 낮아지는지, 둘이 겹치지 않는지 본다 (R4)
4. `√` → 표시줄이 `√(`인지 본다. `1.0×9.8×80)×3.6` `=` → `100.8`
5. 무전 입력란 바로 위에 "계산기 결과 100.8"이 보이는지 본다 (R5). 입력란에 `100.8` → 보내기 → 통과
6. 계산기를 펼친 채 Esc → 계산기만 접히고 카드는 같은 단계에 남는지 본다 (R3)
7. 360×568로 바꿔 계산기를 펼치고 입력란·보내기·다음 버튼을 누를 수 있는지 본다 (R8)
8. 설명 단계로 넘기면 버튼이 사라지고, 다음 무전 단계에서 다시 펼치면 식이 남아 있는지 본다

## 단위 테스트 기준

`answers.md`의 P1~P26(값 상대 오차 1e-12 + 표시 문자열), E1~E21(이유 코드), D1~D15(표시 문자열), §4 미션 식(표시 문자열).
