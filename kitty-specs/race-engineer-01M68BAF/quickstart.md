# Quickstart: 레이스 엔지니어 확인

```bash
pnpm dev     # /episodes/02-race-engineer/
pnpm check
pnpm test:e2e
```

1. M1: 슬라이더로 한계를 넘겨 출발하면 차가 접선 방향으로 밀려나는지 확인
2. M6: 반지름을 키워 "그립 한계 > 최고 속도" → "교점이 축 밖" → "교점 없음(한계 없음)" 순서가 나오는지 확인
3. M7: 코너 4를 틀리면 나머지가 맞아도 불통과인지 확인
4. 360px: 가로 스크롤 없이 M1~M8을 터치로 끝낼 수 있는지 확인
5. 01 에피소드: 기존 테스트와 이전 비교가 변경 없이 통과하는지 확인

사람이 확인: SC-005 처음 보는 학습자가 안내만 보고 M1을 3분 안에 끝내는지.
