# Quickstart: 지진 분석관 확인

```bash
pnpm dev     # /episodes/03-seismic-analyst/  (확인용 바로가기 ?from=M7)
pnpm check
pnpm test:e2e
```

1. M1: 거리 슬라이더를 2배로 옮기면 S-P 시간도 2배가 되는지 확인
2. M2: 판독을 통과하면 확정값 15.0 s로 바뀌고 안내 문구가 나오는지 확인
3. M4: B의 반지름 20 / 21 / 22, 188 / 189 / 190 km에서 교점 개수가 0 / 1 / 2 / 2 / 1 / 0인지 확인
4. M6: 원 A − 원 C 직선을 넣으면 M5의 두 점 중 하나만 지나는지 확인
5. M7: 판독을 통과하기 전에는 거리 입력이 닫혀 있는지, USGS 점이 해안선(포항·경주 내륙)에 맞게 놓이는지 확인
6. M8: 확대 지도에서 버튼으로 0.1 km씩 움직이며 잔차 제곱합이 줄어드는 쪽을 찾을 수 있는지 확인
7. 360px: 가로 스크롤 없이 M1~M8을 터치로 끝낼 수 있는지 확인
8. 01·02 에피소드: 기존 테스트와 이전 비교가 변경 없이 통과하는지 확인

사람이 확인: SC-005 처음 보는 학습자가 안내만 보고 M1을 3분 안에 끝내는지, SC-006 M4에서 두 원의 식을 빼는 이유를 이해하는지.
