# Answers and Verification: 지진 분석관 — S-P 시간 차와 원의 교점

검토 에이전트는 `spec.md`의 M1~M8을 먼저 직접 푼 뒤 이 파일과 비교할 것.

## 공통 식

- P파 도착 t_P = d / Vp, S파 도착 t_S = d / Vs (같은 시각에 출발)
- S-P 시간: Δt = d/Vs − d/Vp = d (Vp − Vs) / (Vp Vs)
- 거리: **d = Δt · Vp Vs / (Vp − Vs)**. Vp = 6.0, Vs = 3.5 → Vp Vs / (Vp − Vs) = 21 / 2.5 = **8.4 km/s**, d = 8.4 Δt
- 원: (x − a)² + (y − b)² = r²
- 두 원의 식을 펼치면 x² + y² − 2a x − 2b y + (a² + b² − r²) = 0. 원 P에서 원 Q를 빼면 이차항이 사라진다:
  **2(a_Q − a_P) x + 2(b_Q − b_P) y = (a_Q² + b_Q² − r_Q²) − (a_P² + b_P² − r_P²)**
- 교점 개수: 중심 거리 D에 대해 D > r₁ + r₂ 또는 D < |r₁ − r₂| → 0개, D = r₁ + r₂ 또는 D = |r₁ − r₂| → 1개, 그 사이 → 2개 (D = 0, r₁ = r₂인 같은 원은 이 에피소드에 나오지 않음)
- 잔차: e_i = |P − S_i| − r_i, 잔차 제곱합 F(P) = Σ e_i²

## M4

- 탐색: 중심 거리 AB = 84. B의 반지름 r_B가 21 또는 189이면 접함(1개), 21 < r_B < 189이면 2개, r_B < 21(원 B가 원 A 안) 또는 r_B > 189(원 A가 원 B 안)이면 0개. 슬라이더 범위 0 ~ 250에 두 경계가 모두 들어 있음
- Answer: r_B = 8.4 × 7.5 = **63 km** (통과 61 ~ 65)
- 펼친 식: 원 A x² + y² − 32x − 154y − 4840 = 0 (256 + 5929 − 11025 = −4840), 원 B x² + y² − 200x − 154y + 11960 = 0 (10000 + 5929 − 3969 = 11960)
- 직선: A − B → 168x − 16800 = 0 → **x = 100**, 즉 (a, b, c) = (1, 0, 100) 또는 그 상수배 (168, 0, 16800), (−1, 0, −100) …
- 판정 규칙: (a, b) ≠ (0, 0)이고 a·0 − b·1 = 0, a·100 − c·1 = 0 (정답 (1, 0, 100)과의 외적 조건). 소수 입력 대비 허용: 입력 계수를 절댓값 최대 성분으로 나눈 정규형이 정답 정규형과 성분마다 1e-6 이내 (부호를 맞춘 뒤)
- 참고: A와 B의 y좌표가 같아 직선이 수직이 된다. 첫 경험에서 계산이 깔끔하도록 고른 배치. 일반 직선은 M8의 계산(설명용)과 M7의 지도에서 나온다
- Verification: 단위 테스트(상수배·부호 반전 통과, 다른 직선 불통과, a = b = 0 거부)
