# Answers and Verification: 지진 분석관 — S-P 시간 차와 원의 교점

검토 에이전트는 `spec.md`의 M1~M8을 먼저 직접 푼 뒤 이 파일과 비교할 것.

## 공통 식

- P파 도착 t_P = d / Vp, S파 도착 t_S = d / Vs (같은 시각에 출발)
- S-P 시간: Δt = d/Vs − d/Vp = d (Vp − Vs) / (Vp Vs)
- 거리: **d = Δt · Vp Vs / (Vp − Vs)**. Vp = 6.0, Vs = 3.5 → Vp Vs / (Vp − Vs) = 21 / 2.5 = **8.4 km/s**, d = 8.4 Δt
- 원: (x − a)² + (y − b)² = r²
- 두 원의 식을 펼치면 x² + y² − 2a x − 2b y + (a² + b² − r²) = 0. 원 P에서 원 Q를 빼면 이차항이 사라진다:
  **2(a_Q − a_P) x + 2(b_Q − b_P) y = (a_Q² + b_Q² − r_Q²) − (a_P² + b_P² − r_P²)**
- 교점 개수: 중심 거리 D에 대해 D > r₁ + r₂ 또는 D < |r₁ − r₂| → 0개, D = r₁ + r₂ 또는 D = |r₁ − r₂| → 1개, 그 사이 → 2개 (D = 0, r₁ = r₂인 같은 원은 이 에피소드에 나오지 않음)
- 잔차: e_i = |P − S_i| − r_i, 잔차 제곱합 F(P) = Σ e_i²

## 판정 원칙 (스펙 "중간값 확정 규칙", 검토 R1·R7·R8·R12 반영)

- 판독값·거리·반지름 같은 중간값은 허용 오차 안이면 통과하고 **즉시 정답값으로 확정**된다. 이후 판정(M3 후보 판정, M4·M6 직선, M5·M6 교점, M7 원 그림)은 모두 확정된 정답값으로 계산한다
- 그래서 판독 ±0.3 s(= ±2.52 km)와 거리 ±2 km가 서로 맞물리지 않아도 방법이 맞는 학습자가 떨어지지 않는다. 확정 표시를 무시하고 자기 판독값으로 거리를 계산하면 떨어질 수 있으므로 안내 문구로 확정값을 짚는다 (검토 m1)
- 판정 기준값과 표시값을 나눈다: 판정은 아래 정밀값(테스트 기준)과의 거리·오차로, 화면 표시는 소수 둘째 자리까지

## M8 (심화)

- 판독값 (검토 m6 반영으로 세 관측소 모두 0.5 s씩 어긋나게 바꿈): A **12.0 s**(참값 12.5), B **7.0 s**(참값 7.5), C **10.5 s**(참값 10.0) → 반지름 **100.8, 58.8, 88.2 km**
- ① (100, 140)에서: e_A = 105 − 100.8 = **+4.2**, e_B = 63 − 58.8 = **+4.2**, e_C = 84 − 88.2 = **−4.2** → **F = 3 × 4.2² = 52.92 km²** (통과 52.82 ~ 53.02)
  - 잔차를 그냥 더하면 4.2 + 4.2 − 4.2 = 4.2로, −가 +를 지워 어긋남이 실제보다 작아 보인다 → 제곱해 더하는 이유 (검토 R4). 예를 들어 잔차가 (+3, −3, 0)인 점은 그냥 더하면 0이지만 두 원에서 3 km씩 벗어나 있다
- ② 잔차 제곱합 최소점: **(96.5816, 136.1635)**, F_min = **1.3913 km²**. 잔차 e_A = −0.831, e_B = +0.462, e_C = −0.697 (통과 = 최소점에서 1 km 이내, 표시는 (96.58, 136.16))
  - 최소점에서 1 km 떨어지면 방향에 따라 F = 2.41 ~ 3.36으로 커진다 (약 2배). 1 km 격자 확인 (97, 136)에서 1.65
  - 확대 지도 범위: x 88 ~ 108, y 128 ~ 148 (20 km × 20 km). 추정점 시작 위치는 (100, 140). 최소점과 시작점 모두 범위 안
  - 지도(−100 ~ 300 km) 1 km 격자에서 국소 최소는 이 점과 (136, 59) 부근(F ≈ 802) 둘뿐. 먼 최소는 확대 범위 밖이라 갈 수 없음
  - 경사 확인: ∂F/∂x ≈ 4e-10, ∂F/∂y ≈ −2e-9
- ③ 최소점은 (100, 140)에서 **5.14 km** 떨어져 있다. 진짜 진앙에서의 F(52.92)가 최소점의 F(1.39)보다 훨씬 크다 → 세 원이 최소점 근처에서 거의 한 점에 모이지만 진짜 진앙은 아니다: "측정에 가장 잘 맞는 점 ≠ 진짜 진앙" (C-007)
- 근심을 쓰지 않는 이유 (C-006, 사람 결정 근거): 이 판독값에서 근심은 (97.90, 133.00)으로 진짜 진앙에서 7.31 km, F = 13.43. 판독값을 ±0.5 s씩 바꾼 26가지 조합에서 근심은 항상 세 교점이 만드는 작은 삼각형 밖이었고, 진짜 진앙까지 2.4 ~ 22.6 km였다 (최악: 13.0 / 7.0 / 10.5 s)
- Verification: 가우스–뉴턴 수렴값, 촘촘한 격자 최소값, ∇F = 0을 서로 비교. NFR-003의 M8 ② 예외 기준(최소점 1e-6 km, F 1e-6 km²) 적용 (검토 m11). 같은 시작점·같은 정지 조건으로 결정적
