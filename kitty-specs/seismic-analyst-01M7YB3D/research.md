## R2. 해안선 데이터 (사람 결정, 2026-11-21)

- **Decision**: Natural Earth 10m 육지(`ne_10m_land.geojson`)를 한 번 내려받아 `scripts/build-coastline.mjs`(Node 내장 모듈만)로 변환하고, 결과 `episodes/03-seismic-analyst/src/model/coastline.ts`만 커밋한다
- **변환 단계**: 경도 127.5~130.7°E, 위도 34.5~37.3°N 상자로 다각형 고리를 자름 → C-010 환산(원점 35.0°N·128.0°E, φ_ref 36.0°, R 6371 km)으로 km 좌표 → 0.1 km 반올림 → 거리 0.3 km 미만 연속 점 제거 → 지도 범위(−20~220 km)만 남김
- **출처 고정**: https://raw.githubusercontent.com/nvkelso/natural-earth-vector/ace5fed0eaf3c6c03c951e75b439ba8fffbc218e/geojson/ne_10m_land.geojson (해당 파일 마지막 커밋 2021-12-08). 2026-11-21 내려받은 파일 SHA-256 `1ac90796408bc6ad6911d69448485d3c4dbf2190370080368a09976e1c9f7416`, 10,157,965 바이트. 스크립트는 해시가 다르면 멈춘다
- **라이선스**: 퍼블릭 도메인, 저작자 표시 불필요 (https://www.naturalearthdata.com/about/terms-of-use/). 그래도 생성 파일 머리 주석에 출처를 적는다(PRJ-001)
- **공급망**: npm 패키지 추가 없음. 원본 데이터는 데이터일 뿐 실행하지 않으며 저장소에 넣지 않는다(`.gitignore`). 생성 파일 크기 목표 30 KB 이하
- **Adversarial evidence**: `deferred_with_rationale` — 새 의존성이 없고, 외부 입력은 해시로 고정된 JSON 하나를 빌드 전에 사람이 한 번 변환하는 것뿐이라 적대적 검토를 생략한다. 생성물은 숫자 배열만 담는다
- **Alternatives**: 50m 해상도(해안이 거칠게 보임, 사람이 기각), 런타임 타일 지도(네트워크·저작자 표시·제스처 충돌, NFR-007 위반)

## R3. 렌더링: Canvas 2D

- **Decision**: 지도·원·직선·지진 기록·두 파 애니메이션을 Canvas 2D로 그린다. 조작 요소(입력·버튼·마커 조절 버튼)는 DOM
- **Rationale**: 02와 같은 방식. 테마 색은 02의 WebKit 대응처럼 로드 뒤 CSS 변수를 다시 읽는다(Issue #36의 교훈을 03에서 처음부터 적용)
- **Alternatives**: SVG — 원·직선은 편하지만 02와 다른 방식이 늘어남

## R4. 지진 기록 시간축 (스펙 검토 R9·R10 반영)

- **Decision**: 가로축은 기록 시작부터의 초. 구간은 P 3 s 전 ~ S 5 s 뒤. 마커는 0.1 s 스냅, ◀ ▶ 버튼으로 0.1 s씩
- **파형**: 고정 모양 합성 그림(난수 없음). 잡음은 결정적 사인 합으로 만들고 P 도착 뒤 진폭이 커지며 S 도착 뒤 더 커진다. 첫 도착 시각이 눈으로 분명해야 한다
- **Rationale**: 발생 시각을 숨겨 P 도착 시각 × Vp 지름길을 막는다. 360px에서 23 s 구간이면 1 s ≈ 14 px, 0.3 s ≈ 4 px라 버튼이 필요하다

## R5. 교점 개수 판정과 부동소수

- **Decision**: 중심 거리 D와 반지름으로 개수를 먼저 판정한다. D², (r₁ ± r₂)²를 비교하고 상대 허용 1e-12로 접함을 판정한다. M4 슬라이더는 1 km 간격 정수이고 경계 21·189도 정수라 정수 연산으로 정확히 맞는다
- **테스트**: r_B = 20 / 21 / 22, 188 / 189 / 190에서 0 / 1 / 2 / 2 / 1 / 0. 속성 테스트: 임의의 두 원에서 개수 2이면 두 교점이 두 원 위(1e-9)와 두 원의 직선 위에 있다

## R6. 잔차 제곱합 최소점 (M8 ②)

- **Decision**: 가우스–뉴턴, 시작점 (100, 140), 갱신량이 1e-12 km 미만이 되거나 100회에서 멈춤. 결과를 기준값 (96.5816, 136.1635)과 1e-6 km로 비교한다
- **독립 기준**: 0.01 km 격자 최소, 수치 경사 ∇F ≈ 0
- **Rationale**: 닫힌 해가 없다. 근심은 쓰지 않는다(C-006)
- **판정**: 학습자의 점과 기준 최소점의 거리 ≤ 1 km

## R7. 직선 같음 판정

- **Decision**: (a, b) = (0, 0)이면 거부. 절댓값이 가장 큰 성분으로 나눈 뒤 첫 0 아닌 성분이 양수가 되게 부호를 맞추고, 정답 정규형과 성분마다 1e-6 이내면 같은 직선
- **테스트**: (1, 0, 100), (168, 0, 16800), (−1, 0, −100) 통과 / (8, 3, 1220), (336, 126, 51240), (−8, −3, −1220) 통과 / (8, 3, 842) 불통과 / (0, 0, 5) 거부
